📋 How to Run the App

1 Open a new browser tab (Chrome, Firefox, or Edge)
2 Click in the address bar at the top of the browser
3 Copy and paste this URL:
localhost:8000/app-refactored.html

👆 Click to copy

4 Press Enter to load the app

⚠️ Common Mistakes

  • ❌ Don't double-click the HTML file
  • ❌ Don't drag the file to the browser
  • ❌ Don't right-click → "Open with browser"
  • ✅ DO type the URL in the address bar

🔧 Is the Server Running?

The HTTP server must be running on port 8000. If you see "connection refused", the server may have stopped.

To check or restart the server, open Command Prompt in the project folder and run:

python -m http.server 8000

Having trouble? Check the browser console (F12) for error messages.
